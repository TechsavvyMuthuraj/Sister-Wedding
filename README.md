# Sister-Wedding

Auspicious Marriage Celebration of **M. Manju, B.Sc., B.Ed.** & **Dr. M. Muniraj, (PT)., MIAP., D.ACU., CPT.**  
Wedding Date: **17th September 2026** • Venue: **Jayam Mahal, Dharmapuri**  
Developer: **Muthuraj C, B.E., CSE.**

## 🌟 Features
- **Couple Spotlight**: Elegant interactive portraits with Cloudinary CDN sync.
- **Digital Lagnapatrika**: Authentic 4-page wedding invitation viewer.
- **Family Heritage**: Honoring parents and elders from Chinnapangunatham & Pikkampatti.
- **Photo Gallery**: PixelTransition memory cards, multi-category filters, Cloudinary upload & download.
- **Blessings Guestbook**: Real-time wishes synced via Supabase.
- **Interactive Wedding Music**: Background devotional wedding music with floating vinyl disc player.
- **Flutter-style Mobile Navigation**: Smooth bottom navigation bar designed for mobile phones.

## 🚀 Tech Stack
- **Frontend**: React, Vite, TailwindCSS, Lucide Icons, Canvas-Confetti
- **Cloud Image CDN**: Cloudinary
- **Database & Realtime**: Supabase
